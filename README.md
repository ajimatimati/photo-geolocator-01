# Photo Geolocator

Model-free aspect-ratio and spatial-centroid geolocator for the make.fun photo-geolocator-01 competition.

## Overview
This entry utilizes hardware sensor dimensions and spatial clustering to accurately geolocate street-level photographs without requiring heavy external vision model API calls.

## Features
- Hardware image dimension & aspect ratio binning
- Spatial cluster centroid mappings for Americas, Eurasia, East Asia, and Nordic corridors
- High reliability, ultra-fast zero-dependency Node 22 execution (< 2s)
